# Composition Diversity Rules

Any pair of examples must differ in at least four dimensions:

- silhouette
- frame geometry
- primary and supporting symbols
- hierarchy and composition
- material/lighting language
- color system
- emotional tone
- ornament density and negative space
- symmetry/asymmetry
- text/ribbon structure

Changing only color, stone, central icon, or title is a failure. A review set
should include guidance/journey, love/generations, strength/wisdom, and
faith/protection/purpose without forcing those themes onto evidence.

Images must show the complete crest and documents with intrinsic aspect ratio,
safe padding, and contain behavior.

# Evidence-to-Symbol Rules

Pipeline:

Family evidence → dominant meaning → candidate language → constraint check →
composition role → Design Basis → written interpretation.

Rules:

1. Primary symbols require direct family evidence or explicit preference.
2. Supporting symbols require traceable evidence or disclosed visual support.
3. Occasion context cannot override an explicit exclusion.
4. Cultural references require user relevance and must avoid ownership claims.
5. Surname alone never creates a symbol entitlement.
6. Gemstone/celestial elements are optional and never automatic.
7. Conflicting evidence is surfaced for review, not silently resolved.
8. Every visible major element must appear in Design Basis.
9. Unsupported-symbol count must be zero before approval.

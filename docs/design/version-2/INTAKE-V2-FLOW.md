# Intake V2 Flow

Seven adaptive stages:

1. Who and Why
2. Family Structure
3. Life Story
4. Values and Traditions
5. Symbolic Preferences
6. Optional Personal Symbolism
7. Design Direction and Review

Required behavior: autosave, resumable session, back/forward, optional-section
skip, progress, keyboard operation, mobile layout, validation without data loss,
privacy explanations, structured JSON, and final review summary.

Branching examples:

- Memorial occasion opens remembrance, important person, date, and privacy.
- Migration opens origin, destination, journey, and meaningful-place prompts.
- Faith is asked only after explicit relevance and supports avoid/exclusion.
- Gemstone and celestial questions appear only after user opt-in.
- Uploads remain optional and require purpose/privacy explanation.

The system collects only information needed for design. It does not request
government identifiers, payment details, full genealogy, or unnecessary PII.
